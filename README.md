# 🌱⏱ 주간 플래너 & 포커스 타이머

기존 **주간 업무 플래너**에 타임타이머(Time Timer) 스타일 시각 타이머, 정원 키우기,
퀘스트 시스템을 결합한 데스크톱 앱입니다.

## 실행 방법
- `실행.bat` 더블클릭 — 또는 `cd D:\claude\focus-timer` 후 `npm start`
- 브라우저에서 `index.html`을 바로 열어도 동작합니다 (창 고정/미니 모드 제외)

## 기존 플래너 데이터 가져오기
앱(Electron)의 저장소는 브라우저와 별개입니다. 기존 데이터를 옮기려면:
1. 브라우저에서 쓰던 플래너 → **데이터 내보내기** (JSON 저장)
2. 이 앱에서 → **불러오기** 로 JSON 선택
- 또는 양쪽에 같은 GitHub 토큰으로 **☁️ 동기화**를 연결하면 자동으로 같아집니다

## 구성
### 📅 플래너 (주간/월간/위젯)
- 기존 기능 그대로: 우선순위, 기한(D-day), 업무/개인, 드래그 이동, 이월,
  반복 업무, 업무 기록, 메모, Gist 동기화, 내보내기/불러오기
- **할일에 마우스를 올리면 ▶ 버튼** → 그 할일로 즉시 집중 시작
- 집중 세션을 완료한 할일에는 🍅 개수가 표시됩니다

### ⏱ 타이머 탭
- 남은 시간이 **빨간 원판**으로 표시, 시간이 흐르면 반시계로 줄어듦
- 다이얼 드래그 / 프리셋(5~60분) / 직접 입력으로 설정
- `Space` 시작·정지, `R` 초기화 (타이머 화면에서)
- 종료 시 알람 + 작업표시줄 깜빡임 + 알림 + 완료 화면
- 휴식 자동 제안: 30분 미만→5분, 30~54분→10분, 55분 이상→15분 (파란 원판)
- 다른 탭에 있어도 **우측 하단 플로팅 칩**으로 남은 시간이 항상 보입니다

### 🌳 내 정원 & 🗺 오늘의 퀘스트 (타이머 탭)
- ✅ 할일 완료 = 씨앗 🌱 / ⏱ 집중 완료 = 물 💧 (10분당 1개)
- 씨앗 심기·물주기 애니메이션과 함께 🫘→🌱→🪴→🌿→나무로 성장, 완성된 나무는 "나의 숲"에 쌓임
- 매일 리셋 퀘스트 4종 (세션 1회 / 25분 집중 / 할일 2개 / 물 5번) + 올클리어 보너스

### 🖥 창 옵션 (상단, 앱 실행 시)
- 🔔 알람 소리 · 📌 항상 위 고정 · ◱ 미니 타이머 모드(작은 창으로 항상 위)
